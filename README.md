One line, 72 characters: the funniest one-line apology from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it. Entry for the [make.fun competition "The Printer Apology"](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153).

## The hook

The staple diet. The printer does not apologise for jamming — it apologises for eating the staples, shredded into confetti, because the only thing it is ever fed besides cheap paper is toner. A real printer gripe (staples), a fresh angle (not the first "sorry I jammed" joke anyone writes), and the punch lands on the last words.

> Sorry I shredded your staples into confetti — my diet is strictly toner.

72 characters.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the directory). Node 22 stdlib only, no network, no external files.
